## 需求需要创建一个用于构建一个符合TIS 插件规范的用户创建TIS插件的Claude Code Skill技能， Skill名称为`create-plugin`## TIS的插件规范是什么在TIS运行体系中所有所有运行的功能子模块都是以插件的形式呈现的，TIS的插件需要具备的基本特征：1. 插件类必须要实现：tis-plugin/src/main/java/com/qlangtech/tis/extension/Describable.java 接口（无论是直接实现还是通过父类间接实现都可以）2. 插件类中必须要有一个`public`的内部类，该内部类必须要继承于：tis-plugin/src/main/java/com/qlangtech/tis/extension/Descriptor.java（无论是直接继承还是通过父类间接继承都可以）。   并且该内部类需要用 annotation @TISExtension（tis-plugin-sezpoz/src/main/java/com/qlangtech/tis/extension/TISExtension.java）标识3. 插件中的属性需要符合以下要求：   * 必须要以`public` 作为属性修饰符   * 必须要有`@FormField` Annotation作标识4. 具有属性描述文件，例如：tis-plugin/src/main/java/com/qlangtech/tis/manage/common/UserProfile.java，   在相同包路径下的resources目录中： tis-plugin/src/main/resources/com/qlangtech/tis/manage/common/UserProfile.json 存在同名文件名，但扩展名为`json`的属性描述文件，内部有`UserProfile.java`中   由于`UserProfile.json`文件中的"help"属性只能表述单行且无格式的帮助信息，如果想让帮助信息为多行且有格式的富文本格式的markdown内容，可以在`.json`文件所在的目录中添加一个`UserProfile.md` 文件，内部可以用`## fieldKey` 标识添加markdown格式的属性描述信息 例如，以下插件就是标准的TIS插件：1. tis-plugin/src/main/java/com/qlangtech/tis/config/authtoken/impl/DefaultHiveUserToken.java2.    public static final class DftDescriptor extends  Descriptor<ParamsConfig>  {            private static final int MIN_AGE = 1;        private static final int MAX_AGE = 150;        public boolean validateAge(IFieldErrorHandler msgHandler, Context context, String fieldName, String value) {            int age = Integer.parseInt(value);            if (age < MIN_AGE) {                msgHandler.addFieldError(context, fieldName, "不能小于：" + MIN_AGE);                return false;            }            if (age > MAX_AGE) {                msgHandler.addFieldError(context, fieldName, "不能大于：" + MAX_AGE);                return false;            }            return true;        }    }```### 多个属性的联合业务逻辑校验在某些情况下的逻辑校验需要联合多个属性一起校验，例如用户登录相关插件：LoginPlugin Boolean，Integer，Duration，com.qlangtech.tis.plugin.MemorySize，String, java.util.Date, Long 的属性### `聚合属性`属性类型本身就是实现 Describable接口的插件，例如：TISFlinkCDCStreamFactory（/Users/mozhenghua/j2ee_solution/project/plugins/tis-incr/tis-realtime-flink/src/main/java/com/qlangtech/plugins/incr/flink/launch/TISFlinkCDCStreamFactory.java）这个插件很典型。他内部有一个cluser（/Users/mozhenghua/j2ee_solution/project/plugins/tis-incr/tis-realtime-flink/src/main/java/com/qlangtech/plugins/incr/flink/launch/clustertype/ClusterType.java）属性就是聚合属性，`ClusterType`代表使用flink机群的类型抽象，他有三种扩展类型，分别是：1.
